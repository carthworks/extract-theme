# .cursorrules — ExtractDesign Studio Design System Binding

Always reference the tokens defined in @DESIGN.md and @tailwind.config.js before generating or styling any component:

1. Colors: Never use arbitrary hex codes or default Tailwind blues (e.g. bg-blue-600). Strictly use semantic CSS variables: `var(--bg-primary)`, `var(--surface-elevated)`, and `var(--color-accent)`.
2. Spacing: Enforce the detected 8pt grid rhythm (p-2, p-4, p-6, p-8). Never introduce ad-hoc margins like mt-[13px] or px-[19px].
3. Borders: Use 1px translucent borders (`border-white/[0.08]`) with subtle radial gradients instead of heavy opaque borders.
4. Typography: Bind headings to `--font-display` and body to `--font-sans`. Never revert to default browser sans.
5. Micro-interactions: Apply `transition-all duration-200 ease-[cubic-bezier(0.16,1,0.3,1)]` on all interactive triggers.

Quality Assurance

5 Golden Rules for High-End Vibe Coding

Follow these rules to ensure your AI never produces amateur UI again.

1. Ban Arbitrary Hex Codes

Never allow the LLM to invent hex codes in component markup. Mandate that all colors map to var(--color-*) or Tailwind theme classes extracted by ExtractDesign.

2. Enforce the 8pt Rhythm

Tell your AI: "Strictly snap all paddings, gaps, and heights to multiples of 8px (8, 16, 24, 32, 48)." This single constraint eliminates 80% of amateur UI asymmetry.

3. Translucent > Opaque Borders

Modern luxury UI avoids solid gray borders. Demand border: 1px solid rgba(255,255,255,0.08). It subtly adapts across varying dark card backgrounds.

4. Use Real Font Binaries

Don't settle for default system font stacks. ExtractDesign downloads the actual .woff2 font binaries. Bind them in your CSS for authentic typographic hierarchy.

5. Custom Motion Easing

Standard CSS ease-in-out feels sluggish. Enforce cubic-bezier(0.16, 1, 0.3, 1) for swift, springy micro-interactions that feel native to macOS/iOS.
